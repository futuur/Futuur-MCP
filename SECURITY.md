# Security

To report a vulnerability in this server, email **support@futuur.com** with "Security" in the subject. Please do not open a public issue for it.

Include what you found, how to reproduce it, and the version (`npm view @futuur/futuur-mcp version` or the release tag). We will confirm receipt and keep you updated on the fix.

The server runs locally and sends your API keys only to the Futuur API (`https://api.futuur.com`). If you think a key pair was exposed, revoke it at futuur.com → Settings → API keys.
